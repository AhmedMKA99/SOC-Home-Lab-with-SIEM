This document records the build of the monitored Windows endpoint: the VM itself, the Wazuh agent, and Sysmon for enhanced logging.

## Wazuh Agent

The Wazuh agent forwards endpoint telemetry to the Wazuh manager. It was installed using the command generated by the dashboard's **Deploy new agent** wizard.

| Parameter | Value |
|-----------|-------|
| Manager address | 10.0.10.3 |
| Agent name | Windows-Endpoint |
| Agent group | default |

Installation steps:

1. The dashboard wizard generated a tailored PowerShell install command.
2. The command was run in an elevated PowerShell session on the endpoint.
3. The agent service was started with `NET START WazuhSvc`.

**Result:** the agent appeared as **Active** in the Wazuh dashboard.

## Sysmon

Standard Windows Event Logs alone do not give enough visibility for meaningful threat detection. **Sysmon** (System Monitor, from Microsoft Sysinternals) adds detailed logging of process creation, network connections, file changes, and more — the telemetry real SOC detections depend on.

### Installation

```powershell
# Download Sysmon
Invoke-WebRequest -Uri https://download.sysinternals.com/files/Sysmon.zip -OutFile $env:tmp\Sysmon.zip
Expand-Archive $env:tmp\Sysmon.zip -DestinationPath $env:tmp\Sysmon -Force

# Download a baseline configuration
Invoke-WebRequest -Uri https://raw.githubusercontent.com/SwiftOnSecurity/sysmon-config/master/sysmonconfig-export.xml -OutFile $env:tmp\sysmonconfig.xml

# Install Sysmon with that configuration
& $env:tmp\Sysmon\Sysmon64.exe -accepteula -i $env:tmp\sysmonconfig.xml
```

The **SwiftOnSecurity** Sysmon configuration was used — a widely adopted, sensible baseline that defines what Sysmon should and should not log, reducing noise while keeping security-relevant events.

Logging was confirmed locally with:

```powershell
Get-WinEvent -LogName "Microsoft-Windows-Sysmon/Operational" -MaxEvents 3
```

### Forwarding Sysmon to Wazuh

By default the Wazuh agent does not read the Sysmon channel. The agent configuration file was edited to add it:

**File:** `C:\Program Files (x86)\ossec-agent\ossec.conf`

Added inside the `<ossec_config>` block:

```xml
<localfile>
  <location>Microsoft-Windows-Sysmon/Operational</location>
  <log_format>eventchannel</log_format>
</localfile>
```

The agent was then restarted:

```powershell
Restart-Service WazuhSvc
```
